## Projects

### 🧠 Brain Tumor Classification (Bachelor's thesis)
I trained a deep learning model to classify brain MRI scans into multiple tumor classes. Accuracy was only part of the goal: I also wanted to see *why* the model made its decisions.

- Fine-tuned **EfficientNetV2-S** with transfer learning
- Compared attention modules (ECA, GAM, CBAM) to see what actually helps
- Used **Grad-CAM, Grad-CAM++, Score-CAM and SmoothGrad** to visualize what the network focuses on

`Python` `TensorFlow` `Keras` `OpenCV` `Scikit-learn`
